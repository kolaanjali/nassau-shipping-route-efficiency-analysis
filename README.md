# Factory-to-Customer Shipping Route Efficiency Analysis

## Project Overview

This project analyzes shipping route efficiency for Nassau Candy Distributor using logistics and shipment data. The goal is to identify efficient and delay-prone routes, analyze ship mode performance, detect geographic bottlenecks, and generate operational insights using data analytics and visualization techniques.

---

## Objectives

* Analyze factory-to-customer shipping routes
* Calculate shipping lead times
* Identify efficient and inefficient routes
* Compare shipping modes
* Detect regional logistics bottlenecks
* Build an interactive Streamlit dashboard
